# 拾志 · 运营岗位资质刷题

内置题库 2957 题（判断 975 / 单选 1119 / 多选 863），覆盖必考题与 7 个部门。
纯前端离线应用：无需联网、无需安装环境，所有学习数据保存在本机浏览器中。

## 快速开始

### Windows
直接双击 `index.html` 即可使用（Chrome / Edge 均可）。
想要"应用"体验：用 Edge 或 Chrome 打开后，选择「安装拾志 / 作为应用安装」，桌面即出现图标。

### 安卓
方法一：把整个「拾志」文件夹拷贝到手机，用文件管理器打开 `index.html`（选择浏览器打开）。
方法二（推荐）：见下方「局域网 / 在线部署」，然后把网页「添加到主屏幕」，像 App 一样全屏使用。

### iPhone
Safari 无法直接打开本地文件，需要通过 http 访问：
1. 电脑与手机连同一 Wi-Fi，在题库文件夹内运行 `python -m http.server 8080`；
2. iPhone Safari 打开 `http://电脑IP:8080`；
3. 点分享按钮 → 「添加到主屏幕」，即可获得近似原生 App 的体验。
也可以把文件夹部署到任意静态托管（GitHub Pages、Vercel、内网服务器等），手机随时访问并离线缓存。

## 功能一览

- 顺序刷题：按题库顺序推进，自动记忆每个范围的进度
- 组卷考试：20/50/100 题限时模拟卷，自动交卷评分
- 部门专项：8 大部门独立进度、正确率、部门错题
- 遗忘曲线：按 5 分钟 → 30 分钟 → 12 小时 → 1/2/4/7/15 天间隔自动安排复习，答对升级、答错重置，8 级记忆等级
- 背题模式：先读题后看答案，标记「记住了 / 还没记住」
- 闪卡记忆：翻卡自测，忘了 / 模糊 / 记住了三档评分写入复习计划
- 闪电挑战：每题 10 秒抢分
- 生命模式：3 条命无限连答，记录最高连对
- BOSS 战：抽取你的高错率题组成 BOSS，答对扣 BOSS 血、答错掉自己血
- 错题本：答错自动收录，任意练习中连对 2 次自动消灭
- 学习数据：掌握度环形图、近 14 天正确率曲线、12 周热力图、部门/题型正确率、最易错 TOP5、16 项成就墙
- 经验等级与连续打卡

## 数据与备份

- 数据保存在浏览器 localStorage 中，换设备或清浏览器缓存会丢失；
- 「设置 → 数据管理」支持导出 / 导入 JSON 备份，可跨设备迁移进度；
- 建议每周导出一次备份。

## 更新题库

如需更换题库，用 Excel 保持相同列结构（序号/部门/题型/题目/答案/选项A~F），
重新生成 `js/data.js` 即可（生成脚本可再次运行 `gen_data.py`）。
